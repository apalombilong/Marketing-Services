# Moda Marketing

A responsive portfolio and services website for creative design and advertising work. Built with HTML and Tailwind CSS, with a visual gallery and an embedded project inquiry form.

## Features

- Responsive service cards and image galleries using grid layouts.
- Fixed navigation with links to page sections and smooth scrolling.
- Dark visual theme, gradients, hover states, and reusable utility styles.
- Embedded Google Form for project inquiries.

## Stack

HTML · Tailwind CSS via CDN · Google Forms

## Run locally

Clone the repository and open `index.html` in a browser. No build step is required. An internet connection is needed for Tailwind CSS and the embedded form.

## Repository guide

- `index.html` — page structure, Tailwind classes, and form embed.
- Image files — portfolio artwork and advertising examples.
- `CNAME` — custom domain configuration.

## Scope

This is a static frontend website. Inquiry collection is handled by the embedded Google Form; the repository does not contain a backend service.
